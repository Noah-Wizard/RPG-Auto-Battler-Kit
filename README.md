# RPG-Auto-Battler-Kit
Write a quest! -Without having to make the 'game' part of the game...

# Update: 23 February 2026
This kit is in development. You have found it LONG before it is finished and ready for its purpose.

What IS that purpose you ask?

It's to create a simple RPG kit in Godot, with an auto-battler system that will allow prospective and aspiring game designers to practice the principles of writing a video game's story, without all of the hassle of figuring out how to program the battle-part.
